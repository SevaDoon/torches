# «ماذا قال بن عبار عن عنزة؟»

فيلم وثائقي قصير (3:28) عن الشاعر عبدالله بن عبار العنزي، وعن صورة عنزة كما تظهر في شعره وكلامه.

## الحالة: v1 — نسخة عمل (Working Cut)

| الجزء | الحالة |
|---|---|
| البحث ولوحة المصادر | ✅ [`01_RESEARCH_BOARD.md`](01_RESEARCH_BOARD.md) |
| حزمة ما قبل الإنتاج (8 بنود) | ✅ [`02_PREPRODUCTION.md`](02_PREPRODUCTION.md) |
| الصورة: الطباعة، والخريطة، والورق، والإيقاع | ✅ مكتملة وفق السيناريو |
| الصوت: الموسيقى، والأجواء، والمؤثرات، والمزج | ✅ مكتمل (بلا صوت مولّد آلياً) |
| الأرشيف الأصلي (صوت بن عبار، صوره، الدحّة) | ⏳ خانات جاهزة في [`slots/`](slots/README.md)، تنتظر المواد |
| مطابقة نص البيتين المعلَّمين «قيد المطابقة» | ⏳ مع منشوريه في 2021 و2025 |
| تحليل حساب TikTok ‏‎@bn.abbar | ⏳ لم يُشاهَد: الموقع محجوب في بيئة العمل |

النسخة المصيّرة: [`renders/bn-abbar-aneza_v1_workingcut.mp4`](renders/bn-abbar-aneza_v1_workingcut.mp4) — ‏1920×1080، ‏25 إطاراً/ث، H.264؛ الصوت AAC ستيريو، ‎-20 LUFS متكامل، ذروة ‎-3.9 dBFS، مدى ديناميكي 16.8 LU.

## إعادة التصيير

```bash
pip install numpy scipy pillow shapely pyloudnorm   # Pillow مع libraqm لتشكيل العربية
python3 pipeline/render.py            # الفيلم كاملاً 1080p
python3 pipeline/render.py --preview  # نسخة معاينة 540p
```

يحتاج `ffmpeg` (مع libx264)، ويجلب عينات الآلات تلقائياً عبر `pipeline/fetch_assets.sh`.
أي ملف يوضع في `slots/` (مثل `A3.mp4`) يحلّ محل البطاقة المؤقتة في موضعه، صورةً وصوتاً.

## بنية المجلد

| المسار | المحتوى |
|---|---|
| `pipeline/film.py` | **المونتاج**: كل لقطة وعنصر وتوقيت، مطابق للسيناريو |
| `pipeline/cartography.py` | الخريطة المحفورة من بيانات Natural Earth |
| `pipeline/gfx.py` | الطباعة العربية (PIL + raqm)، والورق، والحبيبات، وحركة الكاميرا |
| `pipeline/audio.py` | الموسيقى (بياتي على «ري» بربع تون حقيقي)، والأجواء، والمؤثرات، والمزج |
| `pipeline/render_video.py` | تصيير الصورة على عدة معالجات |
| `assets/` | الخطوط (OFL) والبيانات الجغرافية (ملكية عامة)؛ التراخيص في `assets/NOTICE.md` |
| `slots/` | خانات المواد الأرشيفية الأصلية |
